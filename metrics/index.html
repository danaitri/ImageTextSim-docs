    1. CLIPScore

    CLiPScore computes the cosine similarity between CLIP text and image embeddings.

    Strengths:

    • Fast, lightweight, easy to integrate/implement.

    Weaknesses:

    • Tends to overlook spatial relationships, missing objects and subtle attributes.
    • Low fine-grained compositional accuracy.
    • Lack of interpretability.

    Best case

    • Provides a very coarse/broad alignment score.
    • Can be used when computational cost is a concern.

    2. BLIP-2 (itm/itc)

    BLIP2-itm/itc includes a frozen image encoder and a language Q-Former transformer, trained with Image-Text Contrastive learning (ITC) and Image-Text Matching objectives. In ITC mode, BLIP‑2 generates embeddings for image and text that are trained to have high cosine similarity for true pairs. In ITM mode, BLIP‑2 uses a cross‑modal attention head that outputs a match probability (logit) indicating whether the pair is aligned.

    Strengths:

    • Inherits CLIP-like alignment ability with richer modeling.
    • Captures more fine-grained details than CLIP.
    • Cross‑attention mechanism provides a more direct match signal.

    Weaknesses:

    • Still suffers from coarse-level limitations.
    • Lack of interpretability.

    Use case

    • Easy alternative to CLIP.
    • Broad/coarse compatibility checks.

    3. ImageReward

    ImageReward is a learned reward model using a BLIP encoder (ViT‑L image encoder + transformer text encoder) as backbone, with a small MLP head to regress to human preference scores.

    Strengths:

    • Directly trained with human feedback; closely aligned with human judgments.
    • Implicitly learns both fidelity and aesthetic preferences.
    • Generally outperforms CLIP and BLIP‑2 scores as a filter.

    Weaknesses:

    • Can inherit biases from annotators/datasets.
    • Encodes broad human preference factors beyond strict prompt fidelity.

    Use case

    • Optimizing for human-preferred outputs.
    • Combine with other metrics for pure semantic faithfulness.

    4. TIFA (VQA-based)

    TIFA is a fine‑grained, interpretable faithfulness metric. Unlike embedding‑based scores, TIFA uses Visual Question Answering (VQA) to check consistency between the prompt and image.

    Process: 1. Generate question–answer pairs from the prompt via an LLM. 2. Use a VQA model (e.g., BLIP‑2 or mPLUG) to answer those questions on the image. 3. Compute accuracy of VQA answers as the TIFA score.

    Strengths:

    • Explicitly checks every relevant detail of the prompt.
    • Handles object counts, attributes, and spatial relations.
    • Correlates strongly with human judgments on faithfulness.
    • Focuses on factual coverage, not aesthetics.

    Weaknesses:

    • Computationally intensive.
    • Quality depends on underlying VQA system.

    Use case

    • Prioritize faithfulness to the prompt.
    • Detailed interpretability and high human correlation.
    • Best for prompts with multiple objects, relations, or numeric attributes.

    Summary

    • Each metric trades off speed, memory, interpretability, and compositional accuracy.
    • CLIPScore & BLIP‑2 (ITC): fast screening, coarse alignment.
    • BLIP‑2 (ITM): calibrated match probability, still coarse.
    • ImageReward: strongest human‑preference signal.
    • TIFA: highest faithfulness, interpretability.

    Practical approach: use CLIP/BLIP for initial filtering, then apply TIFA or ImageReward on top candidates for fine‑grained judgment.

    🔄 Cyclic Verification

    A powerful way to evaluate and reinforce cross‑modal alignment is to enforce cycle consistency:

    1. Start with an original text prompt T1.
    2. Generate an image I = Gen(T1).
    3. Caption that image to obtain T2 = Cap(I).
    4. Ideally, T2 should match T1.

    Benefits of cyclic verification:

    • Reference‑free evaluation: No need for human‑written reference captions; the cycle itself provides supervision.
    • Modality gap mitigation: Aligns text‑to‑image and image‑to‑text mappings, ensuring semantic fidelity both ways.
    • Fine‑grained feedback: Any missing details or hallucinations become evident when T2 differs from T1.

    Applying Cycle Consistency in Our Pipeline

    • Text → Image: Use a text‑to‑image model (e.g. Stable Diffusion) to compute I = Gen(T1).
    • Image → Text: Use a captioning model (e.g. BLIP‑2) to compute T2 = Cap(I).
    • Comparison: Measure similarity between T1 and T2, either at the token level (e.g., edit distance) or embedding level (e.g., cosine similarity).

    This cyclic metric can be added as an optional post‑processing step to flag cases where the round‑trip reconstruction deviates significantly.

    Jina CLIP v2 for Long Captions

    For our CLIPScore implementation, we adopt jinaai/jina-clip-v2, a contrastive vision‑language model specifically designed to handle long or truncated text inputs via Matryoshka representations.

  1. Supports multilingual understanding with training in 29 languages.
  2. Handles complex visual content using progressively higher image resolutions.
  3. Matryoshka representations: Enables dynamic truncation of embedding dimensions.
    • Input Length: Supports up to **8192 tokens** for text (vs 77 in standard CLIP).
    • Encoder: Jina-XLM-RoBERTa with RoPE and FlashAttention for long texts.
    • Training: Exposed to long captions and documents in training stages.
    • Representation: Embeddings are robust and compressible via Matryoshka learning.
