    Usage Guide

    Environment

    This code was developed and tested with:

    • Python: 3.10
    • PyTorch: 2.7.0+cu126
    • CUDA Toolkit: 12.6
    • GPU: Tesla V100

    Installation

    1. Create and activate a new Conda environment:
    conda create -n image-text-similarity python==3.10
activate image-text-similarity
    1. Install dependencies via the included script:
    chmod +x setup.sh
 ./setup.sh

    How to run

    Running the Pipeline

    By default, the pipeline entry point is src/pipeline.py. You can select your model and override any config parameters on the command line.

    python src/pipeline.py --model <MODEL>
    • Overrides use the syntax --section.key=value.
    • Replace with one of the supported types/metrics below.
    Model Flag Metric Description Example Config Overrides
    --model clip CLIPScore --model.precision fp16
    --model blip2 BLIP2-itc/itm --model.batch_size 32
    --model tifa TIFA VQA-based --model.precision fp16
    --model image_reward Human preference score --model.batch_size 16

    Custom Overrides

    Configuration

    By default, the pipeline loads settings from conf/config.yaml. Here’s a snippet of the key parameters:

    conf/config.yaml

    input:
  path:       data/raw/challenge_set.csv
  chunk_size: 10000

output:
  path: data/processed/challenge_set_${model.type}.csv

app:
  cache_dir:       data/cache
  ttl_days:        7
  max_connections: 100
  output_columns:
    - url
    - caption
    - score
  use_ray:      true
  ray_workers:  4
  num_gpus:     4
  annoy_index_name: annoy-clip

model:
  type:          clip
  model_name:    openai/clip-vit-base-patch32
  precision:     fp32
  truncation:    true

    You can override any of these by passing --section.key=value flags:

    python src/pipeline.py --model blip2 \
    --model.precision=fp16 \
    --model.batch_size=32 \

    For more info on configuration please see Configuration

    Output Structure

    The code will create a directory with the following structure:

    .
└── <MODEL>
    ├── challenge_set_<MODEL>.csv
    ├── metrics_<MODEL>json
    └── score_distribution_<MODEL>.png

    where is the deployed similarity model.

    • CSV:challenge_set_<MODEL>.csvcontains your input rows plus a new score column.
    • JSON: metrics_<MODEL>.json logs timing, memory, stats, errors, etc
    • PNG: score_distribution_<MODEL>.png visualizes the score histogram.

    For more info on logged metrics please see Logging

    Scaling & Distributed Processing

    To leverage multiple GPUs and/or Ray workers for faster inference:

    1. Switch Ray on/off

    Ray disabled (single process across GPUs):

    python src/pipeline.py --model clip --app.use_ray=False

    Ray enabled (distributed actors):

    python src/pipeline.py --model clip --app.use_ray=True
    1. Specify number of GPUs
    python src/pipeline.py --model clip --app.num_gpus=4
    1. Set Ray worker count
    python src/pipeline.py --model clip \
  --app.use_ray=True \
  --app.ray_workers=8 \
  --app.num_gpus=4
